

Para executar uma Daga no ambiente LINUX siga os passos abaixo:

1. Se conecte no servidor linux. 

2. Vá até a pasta aonde está o certificado de conexão.

Deu um comando PWD 

Resultado tem que dar: 

/home/ubuntu

de um ls para verificar os arquivo dentro da caminho acima. 

ubuntu@ip-172-31-47-90:~$ ls
config  dags  docker-compose.yaml  logs  plugins 


3. De o comando "sudo docker ps" para verificar os contender estão com status de "healthy"

ubuntu@ip-172-31-47-90:~$ sudo docker ps

4. Vá para a pas Dags/

ubuntu@ip-172-31-47-90:~$ cd dags/
ubuntu@ip-172-31-47-90:~/dags$



5. Como não irá ter arquivo nenhum lá dentro, termos que qcriar um arquivo em Python lá. 


ubuntu@ip-172-31-47-90:~/dags$ ls
ubuntu@ip-172-31-47-90:~/dags$
ubuntu@ip-172-31-47-90:~/dags$ touch novadrive.py
ubuntu@ip-172-31-47-90:~/dags$
ubuntu@ip-172-31-47-90:~/dags$ ls
novadrive.py
ubuntu@ip-172-31-47-90:~/dags$ 



6. User o comando mais amigável para edição de aquivos no linux,
chamado nano para colocar o script das dag.py dentro dele.


ubuntu@ip-172-31-47-90:~/dags$ nano novadrive.py 

Após colcar o script da dag.py usar os seguintes comandos abaixo para salvar o arquivo: 

Ctrol + x para salver -> Y -> Enter



7. Der um cat para verificar o codigo dentro do arquivo certinho.


ubuntu@ip-172-31-47-90:~/dags$ cat novadrive.py
